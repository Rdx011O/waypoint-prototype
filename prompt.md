Build the WAYPOINT hackathon prototype as a completely original,
responsive freight intelligence platform.

IMPORTANT:

DO NOT create a generic AI-generated SaaS dashboard.

DO NOT use a common template.

DO NOT use:
- generic glassmorphism
- excessive rounded cards
- gradient blobs
- glowing neon UI
- futuristic cyberpunk styling
- excessive blue/purple gradients
- giant hero illustrations
- random decorative charts
- excessive shadows
- floating dashboard cards everywhere
- generic "AI dashboard" aesthetics
- Dribbble-style visual noise

WAYPOINT should feel like a REAL professional operational system
designed specifically for freight, ports, vessels, roads and cargo.

The design should be UNIQUE, QUIET, PRECISE and FUNCTIONAL.

Think:

"control room instrument"

rather than:

"startup landing page".

========================================================
PRODUCT
========================================================

WAYPOINT

Corridor intelligence for freight —
sea to warehouse door.

WAYPOINT connects:

SEA
↓
PORT
↓
LAND
↓
WAREHOUSE

through a shared route graph.

The platform provides four intelligence layers:

1. Vessel Timing
2. Port Congestion
3. Backhaul Matching
4. Cold-Chain Alerts

The important concept is that these are NOT separate systems.

They are different views of the SAME freight network.

- status indicators

- whitespace where information is not needed

========================================================
COLOR SYSTEM
========================================================

Base:

Warm off-white / very light grey background.

Use dark ink/navy for primary text.

Use a restrained deep blue/teal as the WAYPOINT operational color.

Use:

Green → healthy
Amber → warning
Red → critical
Blue/teal → active/information

Avoid gradients.

Avoid making the whole interface blue.

The map should have its own muted cartographic palette.

The interface should remain readable in bright environments.

========================================================
TYPOGRAPHY
========================================================

Use Inter, IBM Plex Sans, or Manrope.

Prefer:

medium / semibold typography

rather than heavy bold text everywhere.

Use monospaced typography ONLY for:

- coordinates
- timestamps
- vessel IDs
- truck IDs
- shipment IDs
- numerical operational data

This should create a subtle technical character.
